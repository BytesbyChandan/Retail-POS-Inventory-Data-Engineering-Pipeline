**Retail POS & Inventory Data Engineering Pipeline**

An end-to-end data engineering project using Python, AWS S3, IAM, and Snowflake to process retail POS transactions, ERP inventory, and IoT event data. Implements multi-format data ingestion (CSV, JSON, and Parquet), Medallion Architecture (Bronze and Silver layers), Snowpipe for automated ingestion, JSON flattening, data transformation, and Change Data Capture (CDC) using Snowflake Streams, MERGE, and Tasks. Also includes external table creation and exporting transformed data back to AWS S3.
